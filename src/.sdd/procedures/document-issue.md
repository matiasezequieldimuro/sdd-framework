# Documentar issue

## Objetivo

Convertir el reporte inicial en una descripción reproducible del problema, sin afirmar todavía una causa raíz.

## Precondiciones

- El work item está habilitado para la fase `issue`.
- Existe un reporte humano o una referencia verificable al fallo.

## Resultado

Crear `artifacts/issue.md` desde la plantilla. Separar síntomas observados, impacto, pasos de reproducción y contexto aportado de hipótesis no verificadas.
