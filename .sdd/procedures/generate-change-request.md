# Generar Change Request

## Objetivo

Documentar el cambio solicitado contra el comportamiento vigente, sin reemplazar el baseline.

## Precondiciones

- El work item está habilitado para la fase `change-request`.
- Se conocen los artefactos o specs afectados, o se registran como desconocidos.

## Resultado

Crear `artifacts/change-request.md` desde la plantilla. Diferenciar de forma explícita comportamiento actual, esperado, alcance y riesgos.
